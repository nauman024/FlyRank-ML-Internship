## 1. Visual Identity System (The Intentional 3-Element Palette)

A technical portfolio's job is to frame the engineering receipts, never to upstage them with decorative animations or distracting colors.

### Typography
* **Primary / Body Font:** Inter (or system `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto`) — clean, highly readable, standard density for technical case studies.
* **Code / Benchmark Monospace Font:** JetBrains Mono or Fira Code — for terminal logs, SQL queries, metric receipts, and mathematical notation.
* **Hierarchy:** Maximum 3 font sizes: Large Headings (24-28px bold), Section Headers (18-20px semi-bold), Body/Data (14-16px regular).

### Color Palette (Minimal Light Theme)
* **Background (`#FFFFFF` / `#F9FAFB`):** Clean, neutral canvas.
* **Text / Primary Hierarchy (`#111827` Primary / `#4B5563` Secondary):** High-contrast, accessible dark gray/slate.
* **Border & Card Neutral (`#E5E7EB`):** Subtle structural scaffolding for case study cards and benchmark tables.
* **Accent Color (`#0284C7` Slate Cyan / `#0F766E` Deep Teal):** Used strictly for active CTAs, Cal.com scheduling buttons, and key performance deltas (+20.3%).

## 2. The "Frame, Not Upstage" Rule

| Design Element | Amateur / Cluttered Default | "Frame, Not Upstage" Implementation |
| :--- | :--- | :--- |
| **Hero Section** | Giant 3D rotating canvas, dark gradient mesh, floating particles. | Clean typography, explicit 1-line proof statement, and direct action button. |
| **Case Study Cards** | Heavy drop shadows, bright gradient cards, decorative badges. | 1px clean neutral border, structured three-beat layout, monospace metric receipts. |
| **Action / Scheduler** | Hidden in a separate menu or flashing popup modal. | Embedded inline Cal.com scheduler and clean persistent text links. |

## 3. Image Strategy & Selection Judgment (Real Receipts vs. AI Images)

### The Judgment Framework
Generative AI tools can produce hundreds of conceptual 3D renders in seconds. However, for a Lead ML Engineer or Technical Founder, generic stock art weakens credibility. The rule is: **Real technical artifacts always beat AI-generated illustrations.**

* **System Architecture:** Clean SVG / hand-drawn structural diagram (Real Artifact).
* **Benchmark Metric Lift:** Vector chart / terminal execution log (Real Artifact).
* **Pipeline Performance:** DuckDB query plan / data split schema (Real Artifact).
* **Conceptual Stock Art:** Rejected (distracts and reduces trust).

## 4. Case Study Visual Artifact Registry

### Case Study 1: Distributed LLM Inference Cluster
* **Selected Visual:** Clean 2-node Ethernet topology diagram showing tensor layer allocation between primary CPU and secondary node over `exo`.
* **Rejected Alternative:** 3D glowing "AI neural network" brain render.
* **Rationale:** A Lead ML Engineer wants to see actual network topology, VRAM allocation, and transport protocol, not generic futuristic art.

### Case Study 2: Real-Time Edge Vision & Navigation System
* **Selected Visual:** Dual-panel camera feed overlay displaying YOLOv8 bounding boxes paired with directional distance depth zones and FPS counter.
* **Rejected Alternative:** Stylized graphic of a robotic eye or stylized radar wave.
* **Rationale:** Shows actual real-time inference latency (30+ FPS) and proves the system runs on physical edge hardware.

### Case Study 3: Search Performance Opportunity Engine
* **Selected Visual:** Multi-bar performance lift chart comparing Random Forest vs. Heuristic Baseline across F1-score with clear error bounds.
* **Rejected Alternative:** Generic 3D search icon or marketing growth arrow.
* **Rationale:** Quantitative receipts and grouped split validation are the core proof points of the research capstone.

## 5. Visual Consistency Verification Checklist

* [x] **Single Unified Palette:** Exactly one background, one primary text color, and one functional accent color across all sections.
* [x] **Receipts-First Media:** 100% of images are real architectural diagrams, benchmark charts, or interface captures.
* [x] **Scannable Spacing:** Generous whitespace (32px to 48px between sections) to ensure immediate visual scanning.
* [x] **No Unearned Flair:** Zero parallax scrolls, zero distracting cursor effects, and zero auto-playing background media.
