Quantifying and Predicting Search Performance Decay in Large-Scale Web Content

Author: Nauman Ahmed  |  Track: Machine Learning Capstone

Abstract

Search engine traffic decay across digital publications poses a continuous challenge for digital publishers, yet automated remediation often relies on unvalidated heuristic rules. This study evaluates machine learning models for detecting content performance degradation across a multi-client production warehouse dataset of over 79 million daily search log records. We engineer features from Google Search Console (GSC) performance metrics (impressions, average ranking positions, and click-through rates) strictly from a mid-panel observation snapshot (March 2026). Using a client-holdout validation design (GroupShuffleSplit), a Random Forest classifier achieved a validated F1-score of 0.7842, outperforming a fixed heuristic rule-based baseline (F1: 0.5812). These results demonstrate that grouped Machine Learning models provide reliable directional decision-support for prioritizing content updates without introducing data leakage.

1. Introduction & Problem Statement

Digital publishers often experience silent content decay—a persistent drop in search impression share and click-through rates (CTR) as competing web pages update and search engine algorithms evolve. Traditional Content Management Systems (CMS) address this using static rules (e.g., flagging any page untouched for >180 days). However, static rules produce high rates of false positives on evergreen content and false negatives on rapid-decay topics. This paper formulates content performance risk prediction as a supervised machine learning task, comparing multi-feature decision models against heuristic baselines using a client-grouped validation strategy.

2. Data Specification

The study utilizes daily search log records extracted from the FlyRank warehouse snapshot:

  • Data Source: fact_content_daily_performance joined with dim_content.
  • Observation Window: March 2026 (month=2026-03). Future time horizons remain sealed to prevent temporal leakage.
  • Exclusion Criteria: Excluded deleted pages (is_deleted IS TRUE) and low-volume pages (≤ 100 impressions) to mitigate sampling noise.
  • Public-Safety Framing: All URLs and client entities are pseudonymized hashes (content_hash_id, client_hash_id). No private queries or client names are exposed.

3. Methodology

We engineered features available at the moment of decision: average ranking position (avg_position), logarithmic impression volume (log_impressions), and content active span (active_days). To eliminate cross-domain data leakage, we utilized a GroupShuffleSplit (80% train / 20% validation) grouped strictly on client_hash_id. Models are evaluated against a heuristic baseline rule combining expected tier CTR deficits and content age.

4. Results (vs. Baseline)

Model / Baseline Accuracy Precision Recall F1-Score
Heuristic Rule Baseline 0.7120 0.5430 0.6250 0.5812
Random Forest (Grouped Split) 0.8412 0.7650 0.8040 0.7842

The client-grouped Random Forest model achieved a +20.3% improvement in F1-Score over the static heuristic baseline, demonstrating the value of multi-feature non-linear interaction modeling over static threshold rules.

5. Limitations

  • Decision Support Only: Outputs represent statistical risk prioritisation, not causal explanations of search engine ranking algorithms.
  • Unobserved Factors: Does not capture external SERP changes (e.g., AI Overviews, new ads, or sudden off-page backlink shifts).

6. Ranked Recommendations (Action Playbook)

  • REWRITE_METAS_AND_REFRESH: High impression volume with severe CTR deficits in top ranking tiers.
  • UPDATE_CONTENT_BODY: Moderate ranking drift or structural decay over time.
  • MONITOR: Stable baseline performance.

The NO-GO List: Never auto-publish unreviewed AI-generated copy to live production or automate bulk 301 redirects without human editorial review.
